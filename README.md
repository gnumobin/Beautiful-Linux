# 💜 Beautiful Linux

A minimal GNOME customization setup for **Arch Linux and its derivatives**.

### ✨ Features

- 🚦 **GTK4 Traffic Lights** – macOS-inspired close, minimize, and maximize buttons.
- 🧚 **Custom Fastfetch** – Customized layout featuring pink Frieren ASCII art and colorful Nerd Font icons.
- 💜 **Reversal Purple** – Installs and applies the Reversal Purple icon theme.
- 🔤 **JetBrains Mono** – Configures KGX Terminal with JetBrains Mono at size 11.
- 🎨 **Purple Accent Color** – Sets GNOME's accent color to purple.
- 🐟 **Fish Shell** – Installs Fish and sets it as the default shell.
- 🐚 **Oh My Fish** – Installs and configures the Oh My Fish framework.
- 🎨 **Krisleech Theme** – Installs and activates the Krisleech theme for Oh My Fish.
- 📌 **Dash to Panel** – Installs Dash to Panel and applies custom panel settings.


### 📦 Requirements

- Arch Linux and Arch-based distributions.
- GNOME Desktop Environment.
- KGX Terminal.
- Internet connection.
- Sudo privileges.

### 🚀 Installation

```bash
git clone https://github.com/gnumobin/Beautiful-Linux.git
cd Beautiful-Linux
chmod +x install.sh
./install.sh
```

### ⚠️ Notes

- Currently supports Arch Linux and its derivatives only.
- GTK4 customization only changes application window controls.
- Designed for GNOME and KGX Terminal.
- Existing configuration files and GNOME settings may be overwritten.
